# Third-party notices

jMacosTweaker contains no third-party source code and links no third-party libraries. It uses only Apple system
frameworks. XcodeGen is a build-time tool and is not part of the app.

Stats, Macs Fan Control and AlDente informed which features to offer. No code was copied from them. SMC keys, IOKit
properties and data formats used here were checked on real hardware by enumeration, and are marked UNVERIFIED in the
code where their meaning could not be confirmed.
